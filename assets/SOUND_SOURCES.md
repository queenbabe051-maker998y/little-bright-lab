# Sound-effect sources

Animal effects are fetched at workflow runtime from SFXMint's Animal Calls Sound Effects Pack, which labels these downloads CC0. Please re-check the source and licence before each public/commercial release because third-party pages and terms can change.

- Cow moo: https://sfxmint.com/dl/cow-moo-02.mp3
- Duck quack: https://sfxmint.com/dl/animal-duck-01.mp3 (workflow has a fallback URL if this filename is unavailable)
- Dog bark: https://sfxmint.com/dl/animal-dog-bark-25.mp3
- Lion roar: https://sfxmint.com/dl/lion-roar-02.mp3
- Sound pack and stated CC0 licensing: https://sfxmint.com/sets/animal-calls

Visuals, recurring mascot Pip, and background music are generated by this repository's own code. Narration is synthesized locally with espeak-ng.
