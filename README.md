# The Little Bright Lab — Animal Sounds Safari

This repository contains a GitHub Actions workflow that renders a short, vertical educational video for children ages 4–10.

## Create the video
1. Open the **Actions** tab.
2. Select **Create Animal Sounds Safari Video**.
3. Click **Run workflow**, then **Run workflow** again.
4. When the run finishes, open it and download the artifact named **little-bright-lab-animal-sounds-safari**.
5. Unzip the artifact to get the MP4.

The video is rendered at 720×1280 (9:16) with original cartoon-style animal illustrations, English narration, synthesized animal sound cues, and a cheerful synthesized backing track. No external copyrighted video assets are used.
